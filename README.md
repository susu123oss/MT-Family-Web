# MT Family Product Website

MT 家族的用户向产品介绍页。

页面内容基于三个当前生产项目重新梳理：

- **MT 内存工具**：MemoryToolkit-正式版
- **MT 智能体**：CodexApp
- **MT 连点器**：AutoClicker-巨魔版

## 文案原则

这个网页面向用户和潜在用户，不是工程文档。

- 重点解释“这个产品能帮用户做什么”。
- 可以展示功能类别、使用场景、系统支持和安装形式。
- 不公开内部实现路径、底层兼容策略、算法细节、工程绕行方案、构建保护参数或其它不适合产品页披露的信息。
- 不把尚未验证或仅存在于实验分支的能力写成正式产品功能。

## 当前版本

- MT 内存工具：1.8.5
- MT 智能体：1.0.7
- MT 连点器：1.1.5

## 本地预览

直接打开 `index.html` 即可；也可以使用任意静态 HTTP Server 预览。

## 结构

- `index.html` — 页面结构与用户向文案
- `styles.css` — 响应式视觉样式
- `app.js` — 轻量滚动与指针交互
- `assets/` — 三款正式 App 图标与公开产品预览素材
